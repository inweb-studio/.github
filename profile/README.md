# InWebsite

Kami bikin website untuk usaha di Indonesia, dari landing page sampai toko online yang tersambung ke kasir. Selain pesanan klien, kami juga mengurus beberapa produk sendiri:

- InWebsite Kasir, aplikasi kasir (POS) yang tetap jalan saat offline, lengkap dengan dashboard dan website toko.
- Undangin, undangan pernikahan online versi 2D dan 3D.
- InWebChatBot, chatbot yang menjawab dari isi situsmu dan dipasang lewat satu potong kode.
- InWebAsset, kumpulan snippet animasi React + Tailwind yang tinggal disalin.

Kebanyakan repo di sini privat. Kalau mau bikin web atau sekadar tanya, mampir ke [inwebsite.online](https://inwebsite.online) atau Instagram [@inwebsiteofficial](https://instagram.com/inwebsiteofficial).
