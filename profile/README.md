## Yang kami kerjakan

- **Website klien**: landing page, situs usaha, dan portofolio.
- **Toko online**: tersambung langsung ke sistem kasir.
- **Redesain**: membenahi website yang sudah ada tanpa mulai dari nol.
- **SEO**: supaya usaha kamu lebih mudah ditemukan di Google.

## Produk sendiri

Selain pesanan klien, kami juga membangun produk yang dipakai langsung:

| Produk | Untuk apa |
| --- | --- |
| **InWebsite Kasir** | Aplikasi kasir (POS) yang tetap jalan saat offline, lengkap dengan dashboard dan website toko. |
| **Undangin** | Undangan pernikahan online, tersedia dalam tema 2D dan 3D. |
| **InWebChatBot** | Chatbot yang menjawab dari isi situsmu, dipasang lewat satu potong kode. |
| **InWebAsset** | Kumpulan snippet animasi React + Tailwind yang tinggal disalin ke proyekmu. |
